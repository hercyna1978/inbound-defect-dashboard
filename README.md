# 입고 / 불량 데이터 대시보드

`raw_data.xlsx`(시트: `불량`, `입고`)를 읽어서 아래 내용을 보여주는 Streamlit 대시보드입니다.

- **월별 누계 수량 추이** (입고 누계 vs 불량 누계) 그래프
- **공장 분류**: 공급처 상품명에 `C2-S`가 포함 → `C2-S공장`, `C2`가 포함 → `C2공장`,
  `C5`가 포함 → `C5공장`(모두 대소문자 구분 없음), 공란 → `미상`
- **불량타입 분류**: 전표제목 기준 `테` / `렌즈` / `전체` / `기타`
- 상단 필터: **공장별 선택(드롭다운)**, **불량타입**, **상품명 검색**, **상품코드 검색**,
  **데이터 종류(입고/불량)**, **작업일 범위(날짜)**
- **불량타입별 월별 스택 그래프** (테/렌즈/전체/기타가 쌓여서 표시)
- **공장별 고정 색상**: C5공장/C2공장/C2-S공장/미상이 모든 그래프에서 항상 같은 색으로 표시
  (막대의 빗금 무늬 유무로 입고와 불량을 구분)
- 공장별 / 불량타입별 요약 그래프 + 테이블, 상세 데이터 테이블, CSV 다운로드

## 사용법

1. 대시보드에 접속하면(또는 로컬 실행 시) 자동으로 데이터가 로드됩니다.
   (`data/raw_data.xlsx`가 없으면 화면에 나타나는 업로드 버튼으로 엑셀 파일을 올려주세요.)
2. **상단 필터 영역**에서 원하는 조건으로 데이터를 좁힙니다.
   - **공장별 선택**: 드롭다운에서 보고 싶은 공장(C5공장/C2공장/C2-S공장/미상)을 체크
     (기본값은 전체 선택 상태이며, 클릭해서 원하는 것만 남길 수 있습니다)
   - **불량타입**: 테/렌즈/전체/기타 중 보고 싶은 것만 선택
   - **상품명 검색 / 상품코드 검색**: 부분 일치 검색 (대소문자 구분 없음). 예) 상품코드에 `03595` 입력 시 해당 코드가 포함된 행만 표시
   - **데이터 종류**: 입고만, 불량만, 또는 둘 다 볼지 선택
   - **작업일 범위**: 달력에서 시작일~종료일을 선택하면 그 기간 데이터만 집계
3. 필터를 바꾸면 아래 **KPI(총 입고/총 불량/불량률/필터링된 행 수)**와
   모든 그래프·테이블이 즉시 다시 계산되어 표시됩니다.
4. **월별 누계 수량 추이** 그래프에서 입고(파란선)와 불량(빨간선)의 누적 증가 추세를 비교합니다.
   마우스를 그래프 위에 올리면 해당 월의 정확한 수치가 표시됩니다.
5. **월별 수량(누계 아님)** 은 기본적으로 접혀 있으니, 제목을 클릭하면 펼쳐서 월별 단순 수량(막대그래프)을 볼 수 있습니다.
6. **불량타입별 월별 수량(스택 그래프)** 에서 특정 월에 어떤 불량타입이 많았는지 색상별로 확인합니다.
7. **공장별 수량 / 불량타입별 수량** 그래프는 같은 공장(또는 같은 불량타입)이 항상 같은 색으로 표시되고,
   빗금이 있는 막대는 불량, 빗금이 없는 막대는 입고를 의미합니다.
8. 화면 맨 아래 **상세 데이터 테이블**에서 필터링된 원본 데이터를 직접 확인할 수 있고,
   **CSV 다운로드** 버튼으로 현재 필터 결과를 파일로 저장할 수 있습니다.

## 폴더 구조

```
.
├── app.py              # Streamlit 대시보드 메인 코드
├── requirements.txt    # 필요 패키지
├── data/
│   └── raw_data.xlsx   # 원본 데이터 (git에는 커밋되지 않음, 로컬/서버에 직접 배치)
└── README.md
```

> `data/raw_data.xlsx`는 `.gitignore`에 의해 저장소에 커밋되지 않습니다.
> 거래처 연락처·계좌 등 민감한 정보가 포함되어 있을 수 있으므로,
> 공개 GitHub 저장소에는 **코드만 올리고 데이터 파일은 올리지 않는 것**을 권장합니다.
> `data/raw_data.xlsx`가 없으면 앱 실행 시 화면에서 직접 파일을 업로드할 수 있습니다.

## 로컬 실행 방법

```bash
# 1. 저장소 클론
git clone <이 저장소 주소>
cd <저장소 폴더>

# 2. 가상환경(선택) 및 패키지 설치
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3. 데이터 파일 배치
#    data/raw_data.xlsx 위치에 원본 엑셀 파일을 복사
mkdir -p data
cp /path/to/raw_data.xlsx data/raw_data.xlsx

# 4. 앱 실행
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 접속하면 대시보드가 표시됩니다.

## GitHub + Streamlit Community Cloud 배포

1. 이 폴더 전체를 GitHub 저장소에 push합니다. (`data/raw_data.xlsx`는 `.gitignore`로 제외됨)
2. [share.streamlit.io](https://share.streamlit.io) 에서 GitHub 계정으로 로그인 후
   **New app** → 방금 push한 저장소 / 브랜치 / `app.py` 를 선택하고 Deploy 합니다.
3. 배포된 앱에 원본 데이터가 없으므로, 접속 후 화면에 나타나는 업로드 버튼으로
   `raw_data.xlsx`를 직접 업로드하면 됩니다.
   (매번 업로드가 번거롭다면, Streamlit Cloud의 "Secrets" 대신
   비공개 저장소를 사용하고 `data/raw_data.xlsx`를 커밋하는 방법도 가능합니다.
   단, 이 경우 저장소를 반드시 **Private**로 설정하세요.)

## 데이터 처리 로직 요약 (`app.py`)

- `작업일` 컬럼을 날짜로 변환 후 `년-월` 단위로 그룹화
- `공급처 상품명` 값으로 공장 분류
  - `C2-S` 포함(대소문자 무관) → `C2-S공장`
  - `C2` 포함(대소문자 무관, C2-S 제외) → `C2공장`
  - `C5` 포함(대소문자 무관) → `C5공장`
  - 공란/미해당 → `미상`
- `전표제목` 값으로 불량타입 분류
  - `전체` 포함 → `전체`
  - `테` 포함 → `테`
  - `렌즈` 포함 → `렌즈`
  - 그 외 → `기타`
- 필터(공장/불량타입/상품명/상품코드/데이터종류)를 적용한 뒤
  `년월` × `출입구분(입고/불량)` 으로 수량을 집계, 누적합(`cumsum`)하여
  월별 누계 수량 추이 그래프를 그립니다.
